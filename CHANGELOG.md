# Changelog

## [1.0.0] - Initial Public Release

First public open-source release of PAULT.

- Portable Windows one-folder application.
- Offline password-protected vaults using Argon2id and AES-256-GCM authenticated encryption.
- Authenticated chunked file import and export, encrypted metadata, and virtual folders.
- Desktop browsing with search, sorting, multi-selection, image thumbnails and viewing, and external video playback.
- Manual and inactivity locking, password changes, and polling for unavailable vault storage.
