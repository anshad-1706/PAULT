# PAULT v1.0.1 — Documentation Update

PAULT v1.0.1 improves onboarding documentation with a beginner-friendly Windows and USB user guide. It explains portable setup, first-time vault creation, existing-vault access, file and folder use, export limitations, locking, and safe USB ejection.

This is a documentation-only update. It does not change the encryption implementation, vault format, application behavior, or security behavior.
