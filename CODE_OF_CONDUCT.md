# Code of Conduct

The PAULT project adopts the [Contributor Covenant Code of Conduct, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Participants are expected to be respectful, constructive, and inclusive. Harassment and personal attacks are not acceptable. Project maintainers are responsible for applying the adopted Code of Conduct to project spaces.

For a conduct concern, contact the repository maintainers through a private channel configured on the GitHub repository. Do not post private or sensitive information in a public issue.
